# Support — Acing IU: Genesis

---

## How to get help

| Channel | Purpose |
|---|---|
| [GitHub Issues](https://github.com/AcingTime420/Acing-IU-Genesis/issues) | Bug reports and feature requests |
| [GitHub Discussions](https://github.com/AcingTime420/Acing-IU-Genesis/discussions) | General questions and community conversation |
| security@acing-iu.example | Security vulnerabilities (do **not** use public issues) |

---

## Before opening an issue

1. Search existing issues to avoid duplicates.
2. Read `CONTRIBUTING.md` for the development workflow.
3. For security issues, read `SECURITY.md` — **do not open a public issue**.

---

## Issue templates

Use the GitHub issue templates when creating an issue:

- **Bug report** — for confirmed misbehaviour.
- **Feature request** — for new capabilities.
- **Custom** — for anything else.

---

## Response expectations

This project is in early development and is maintained on a best-effort basis.

| Severity | Target first response |
|---|---|
| Security (critical) | 72 hours |
| Bug (blocking) | 1 week |
| Bug (non-blocking) | 2 weeks |
| Feature request | Best effort |

---

## What is not supported

- Undocumented internal APIs or private build artefacts.
- Modifications to the Acing Vault hardware interface outside of the emulator.
- Production deployment on non-Acing-OS devices (this platform targets custom Acing OS ROMs).
