# Genesis Versioning Policy

## Version Control

All architecture, documentation, and software changes are tracked through Git history.

## Change Categories

Major:
Breaking architectural changes.

Minor:
New capabilities that preserve compatibility.

Patch:
Corrections, documentation updates, and fixes.

## Required Records

Changes should include:

- reason
- affected components
- validation results
- security considerations

## Preservation

Historical decisions remain available for audit and future analysis.
